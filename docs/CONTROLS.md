# Controles

| Ação | Dabble GamePad |
|---|---|
| Direção | D-pad ou eixo |
| A / Botão1 | CROSS/X ou CÍRCULO |
| B / Botão2 | QUADRADO ou TRIÂNGULO |
| Iniciar ROM / confirmar | CROSS/X |
| Favorito no catálogo | QUADRADO |
| Buscar | TRIÂNGULO |
| Todos/favoritos/recentes | ESQUERDA/DIREITA |
| Continuar último jogo | START no catálogo |
| Pausa do emulador | START+SELECT por700ms |

Na pausa, X/CÍRCULO confirma e QUADRADO/TRIÂNGULO volta. Slots0–3 são manuais;9 é automático. Configurações incluem vídeo e áudio. O autosave iniciaOFF. O formato de estado é próprio do sistema e não é compatível com estados dos outros emuladores.

START sozinho aciona a pausa do console SMS por NMI; SELECT fica reservado ao combo do menu. Reset pelo menu.
